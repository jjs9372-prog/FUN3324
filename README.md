# 현장사진 정리

현장에서 휴대폰으로 사진을 찍으면 지정된 엑셀 양식으로 자동 작성해 주는 도구입니다.
**업무 3가지가 파일 하나에 들어 있습니다.**

- 접속 주소 : `https://<깃허브아이디>.github.io/<저장소이름>/`
- 설치할 것 없음 (브라우저만 있으면 동작)
- 촬영한 사진과 만들어진 엑셀은 **서버로 전송되지 않고 사용한 기기 안에만** 저장됩니다.

## 들어 있는 업무

| 업무 | 만들어지는 것 |
|---|---|
| **지중표시기 보강** | 사진 수만큼 칸이 오른쪽으로 늘어나는 `현장 작업사진` 양식 |
| **IoT 맨홀 점검** | `IOT 맨홀 시설 점검표` (사진칸 6개 고정, 양호/불량 빨간 동그라미 표시) |
| **과기부 국사 수검** | `정산요청 세부` 양식. 월별로 국사를 모아 **가로로 누적** |

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면·엑셀 생성기·양식 3종이 모두 이 파일 하나에 들어 있음) |

## 국사 수검 — 월/국사 관리 방식

1. **월 추가** (예: `2026-08`) → 월마다 따로 보관됩니다.
2. 월 안에서 **국사 추가** (지역 + 국사명 + 점검 맨홀 수).
   - 화면은 **맨홀 번호별로 묶여** 있습니다. `점검 맨홀 #1` 구획 안에
     시건장치 · 사다리/침수 · 함체/케이블 · 관구/내관 4칸이 들어 있어
     현장에서 맨홀 하나씩 끝내며 찍기 좋습니다.
   - 맨 앞 구획은 `점검 국사 전경` 3칸 (전경 · 명판 · SKT유선 Infra 확인 스캔본)
   - **점검 맨홀 수는 기본 4개, 6개까지** 늘릴 수 있습니다. 늘리면 그 국사의 엑셀 블록이
     맨홀 1개당 2열씩 오른쪽으로 넓어지고, 뒤 국사들이 그만큼 밀립니다.
   - 사진칸 하나에 **2장까지** 넣을 수 있고, 2장이면 칸을 **좌·우 반반**으로 나눠 놓입니다.
3. 국사를 추가할수록 엑셀에서 블록이 **오른쪽으로** 늘어납니다.
   지역(수도권·동부·서부·중부)마다 세로 구간이 따로 있고, 각 지역은 **최대 18곳**까지입니다.
4. 맨 위 정산 요약(구분·정산대상·정산금액)은 국사 수 × 단가로 자동 계산됩니다.

기존 월은 그대로 두고 새 월을 추가하면 됩니다. 사진은 기기에 남아 있으므로
나중에 그 달을 다시 열어 국사를 더 붙이고 엑셀을 새로 만들 수 있습니다.

## IoT 맨홀 — 저장 범위와 시트 이름

- **`1 기본 정보`(점검자·점검일·SK관리번호·수리항목)만** 다음에 열었을 때 그대로 채워집니다.
  `2 현장 점검항목` · `4 조치 내용`은 맨홀마다 새로 쓰는 값이라 앱을 다시 열면 비워집니다.
- **사진은 새로고침해도 남습니다.** 실수로 새로고침해도 다시 찍지 않아도 됩니다.
  다만 **앱을 닫았다 다시 열면** 다음 맨홀을 위해 사진도 지워집니다.
- 엑셀 **시트 이름이 점검일을 따라갑니다**. 점검일이 2026-02-23 이면 시트 이름은 `0223.SKO 강남`.
  뒷부분(`.SKO 강남`)은 `SHEET_SUFFIX` 한 줄로 바꿀 수 있습니다.

## IoT 맨홀 — 입력 방식

- **수리항목** · **고장원인** : 목록에서 눌러 여러 개 고릅니다. 쉼표로 이어져 엑셀에 들어갑니다.
  목록에 없는 것은 아래 **직접 입력** 칸에 적으면 됩니다 (여러 개는 쉼표로 구분).
- **조치 이력** : 수리항목에서 고른 값이 그대로 자동으로 들어갑니다.
- **현장 점검항목** : 6개 모두 **양호가 기본**입니다. 불량인 것만 눌러 바꾸면 그쪽에 빨간 동그라미가 그려집니다.
- **사진** : 고장원인 칸 4개는 **2장까지** 넣을 수 있고, 2장이면 칸을 **좌·우 반반**으로 나눠 놓입니다.
- **빨간 동그라미** : 고장원인 칸에 **사진을 먼저 넣어야** 표시할 수 있습니다.
  1. 고장원인 칸에서 `촬영` 또는 `앨범`으로 사진을 넣는다
  2. 사진을 누르거나 `🔴 표시하기` 단추를 누른다 → 사진이 크게 열린다
  3. 피해 지점을 누르면 그 자리에 빨간 동그라미가 찍힌다 (PC는 마우스 클릭, 휴대폰은 손가락)
  4. `완료` → 동그라미가 사진에 새겨져 엑셀에 들어간다

  크기 3단계(작게·보통·크게), `되돌리기`, `전부 지우기`를 쓸 수 있습니다.
  맨홀 전경 칸에는 이 기능이 없습니다.

## 사진이 칸에 들어가는 방식

- **지중표시기** : 사진칸 비율(181×158)에 맞춰 가운데를 잘라 칸에 꽉 채웁니다.
- **IoT 맨홀** : 병합된 사진칸에 **꽉 차게** 넣습니다(비율은 유지되지 않음).
  셀 모서리에 앵커를 걸어 엑셀이 직접 크기를 맞추므로 칸을 넘거나 어긋나지 않습니다.
  이 양식의 기본 글꼴은 Calibri 9pt 라서 열 너비 1단위 = **6px** 입니다 (B/D=123px, C/E=220px).
- **국사 수검** : 맨홀과 동일하게 **꽉 차게** 넣습니다. 사진칸 1개는 2열 × 8행입니다.

## 파일을 열었을 때

세 업무 모두 **왼쪽 맨 위(A1)에서 열립니다**. 양식 원본에 저장돼 있던 화면 위치
(수검 양식은 `AN열`)를 지우고 A1 로 맞춥니다. 확대 비율은 양식 값 그대로 둡니다
(수검 70%, 맨홀 85%).

## 자주 바꾸는 값

`index.html` 안 `공통 앱 도구` 부분 상단에 모여 있습니다.

```js
const MAX_SIDE = 1280;      // 사진 긴 변 최대 픽셀
const JPEG_Q   = 0.8;       // 사진 화질
const FILE_EXT = '.xlw';    // 내려받을 파일 확장자 ('.xlsx' 로 바꿔도 됨)
```

## 정산 단가

국사 수검의 **정산 단가는 코드에 넣지 않습니다.** 앱 화면(`정산 월 → 정산 단가`)에서
직접 입력하고, 그 값은 입력한 기기에만 기억됩니다. 비워 두면 엑셀의 정산금액 칸도
빈 채로 만들어집니다.
