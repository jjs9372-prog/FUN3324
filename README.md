# 지중표시기 현장사진 정리

현장에서 휴대폰으로 사진을 찍으면 지정 엑셀 양식으로 자동 작성해 주는 도구입니다.

- 접속 주소 : `https://<깃허브아이디>.github.io/<저장소이름>/`
- 설치할 것 없음 (브라우저만 있으면 동작)
- 촬영한 사진과 만들어진 엑셀은 **서버로 전송되지 않고 사용한 기기 안에만** 저장됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면·엑셀 생성기·양식이 모두 이 파일 하나에 들어 있음) |

## 자주 바꾸는 값

`index.html` 안 `앱 로직` 부분 상단에 모여 있습니다.

```js
const FILE_EXT   = '.xlw';   // 내려받을 파일 확장자
const MAX_SIDE   = 1280;     // 사진 긴 변 최대 픽셀
const JPEG_Q     = 0.8;      // 사진 화질
```
